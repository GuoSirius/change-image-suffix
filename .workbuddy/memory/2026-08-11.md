## 新增空白裁剪功能 (crop 子命令)
- 给 change-image-suffix 加了 `cis crop` 子命令：裁掉图片四周透明 / 纯白 / 自定义背景色，输出到 `<原目录>/cropped/`，文件名保持不变。
- 参数：`-b/--bg <r,g,b>` 自定义背景色、`--padding <n>` 边距（默认 0）、`--tolerance <n>` 背景色容差（默认 10）、`--white-tolerance <n>` 白底容差（默认 8）。
- 右键菜单在悬停子菜单新增「📐 裁剪空白」项，命令为 `node script --pause crop <arg>`。
- 核心实现：sharp.ensureAlpha().raw() 读像素 → 扫描非空白包围盒 → extract 裁剪。
- 已用示例大图验证：3000×1688 → 481×1085（移除 89.7% 空白），padding=10 生效（501×1105）；转换模式回归正常。
- 已 `npm run build`、提交并推送 gitee main。
